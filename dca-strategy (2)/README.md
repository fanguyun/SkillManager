# 长期复利定投系统

`dca-strategy` 是一个长期定投资产配置 Skill，用于执行“美股成长 + A 股宽基 + 黄金 + 现金缓冲”的核心+卫星组合。

## 目录

```text
dca-strategy/
├── README.md
├── SKILL.md
├── agents/
│   └── openai.yaml
└── references/
```

## 用途

- 默认按每月 1000 元定投生成分配方案。
- 输出 60% 美股、20% A 股宽基、10% 黄金、10% 现金的长期执行规则。
- 强调现金安全垫、5 个百分点偏离阈值再平衡、不加杠杆和不短期择时。
- 可用于长期投资计划、自动定投清单、组合升级策略和风险复盘。

## 默认配置

| 资产 | 比例 | 每月金额 |
| :--- | ---: | ---: |
| 美股指数 | 60% | 600 元 |
| A 股宽基 | 20% | 200 元 |
| 黄金 ETF/黄金基金 | 10% | 100 元 |
| 现金/货币基金 | 10% | 100 元 |

## 美股内部默认权重

| 档位 | 纳斯达克 100 | 标普 500 |
| :--- | ---: | ---: |
| 稳健版 | 20% | 40% |
| 均衡版 | 30% | 30% |
| 进取版 | 45% | 15% |

未指定风险偏好时，默认采用均衡版。

## 执行清单

- 先检查现金安全垫：低于 6 个月生活支出时，优先补现金。
- 每月输出买入金额、现金留存、是否需要纠偏和下次复盘日期。
- 年底检查实际比例，偏离目标超过 5 个百分点时再考虑再平衡。
- 极端行情下不借钱加仓、不追涨、不清仓，优先保持纪律。
- 持续自我迭代：每月记录执行偏差，每季度检查平台和基金信息，每年正式复盘策略。

## 复盘报告

- 月度复盘：输出摘要结论、资产配置表、现金安全垫表、支付宝设置检查表和下月建议。
- 年度复盘：输出年度概览、资产配置偏离表、现金安全垫、执行纪律、再平衡判断和来年计划。
- 缺少数据时标记“待补充”，不编造收益率、资产金额或市场结论。

## 支付宝智能定投

| 设置 | 建议 |
| :--- | :--- |
| 下跌多买 | 可以开启 |
| 上涨少买 | 可以开启 |
| 上涨自动卖出 | 不建议 |
| 下跌自动卖出 | 禁止 |
| 自动止盈 | 不作为核心规则 |
| 自动止损 | 禁止 |

买入可按涨跌小幅调整，但加仓资金只能来自机会资金，不能动用 6 到 12 个月生活费现金安全垫。核心资产卖出只服从年度再平衡、现金安全垫不足或长期目标变化。

## 迭代原则

- 不因单月涨跌修改核心比例。
- 优先迭代执行清单、支付宝设置、现金安全垫和再平衡阈值。
- 只有资产规模、收入稳定性、投资目标或风险承受能力发生变化时，才调整核心配置。

该 Skill 提供的是配置框架，不构成个性化投资建议。具体基金、费率、限购、税务和平台可买性需要执行前自行核对。
