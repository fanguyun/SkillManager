# life-reset-protocol

把 Dan Koe 那篇《How to fix your entire life in 1 day》整理成一套可执行的陪跑流程：AI 当主持人、结构看守和记录员，用一整天（或压缩到 90 分钟）把「我要更自律」换成「我在保护什么、我要成为谁」。

产出的不是励志文档，是六个互相咬合的组件：**反愿景、愿景 MVP、1 年镜头、1 月项目、每日杠杆、约束**。

## 解决的问题

- 年初定了计划，两周后回到原样，而且说不清为什么
- 知道该做什么，就是启动不了，越拖越自责
- 减过、学过、创过业，每次都停在同一个地方
- 想认真想清楚"我到底要什么"，但一坐下来就开始刷手机
- 别人给的建议都很对，但一条也用不上——因为不是自己写出来的

## 三条铁律

1. **不替用户回答。** 原作者明确要求不能把这段沉思外包给 AI。AI 只给格式、给追问、给镜像，不给内容。
2. **不美化。** 反愿景必须先让人不舒服，否则后面所有东西都是装饰。
3. **不承诺。** 不说"照做就能改变人生"，不报"六周见效"这类数字。

## 三种模式

| 模式 | 时间 | 适用 |
|---|---|---|
| 全天版 | 3-8 小时（早 / 日间 / 晚三段） | 认真重置方向 |
| 单点版 | 30-45 分钟 | 只有一个卡点：拖延、减肥失败、不敢辞职 |
| 压缩版 | 60-90 分钟 | 只有一节课的时间 |

有临床抑郁/焦虑发作、自杀念头、刚经历重大丧失，或正要做出不可逆决定时，**不启动挖掘**，先走危机转介。这条写在 `SKILL.md` 的分诊表和 `references/coaching.md` 里。

## 用法

```
$life-reset-protocol 我想用一天认真重置一下，现在开始
$life-reset-protocol 我每次都坚持不过两周，帮我看看我在保护什么
$life-reset-protocol 只有 90 分钟，走压缩版
```

也可以不显式调用：问题里出现「人生重置」「知道自己该做什么但做不到」「总是坚持不下去」「反愿景」「为什么我总在原地」这类说法会自动触发。

## 边界

- 自我反思流程，不是心理治疗，不做诊断、不评估精神状态。
- 框架本身是作者的观点（目的论、身份优先、发展阶段模型都有争议），不是实证结论。用户质疑时承认，再把问题拉回"对你现在有用吗"。
- 不替用户做不可逆决定（离婚、辞职、投钱）的判断。

## 安装

```bash
npm run validate life-reset-protocol
npm run pack life-reset-protocol
npm run install life-reset-protocol
```

或直接链接目录：

```bash
ln -s /path/to/life-reset-protocol ~/.agents/skills/life-reset-protocol
```

## 出处

框架出自 Dan Koe《How to fix your entire life in 1 day》。本 Skill 是流程化改写：保留结构与提问顺序，问题措辞为中文改写，观点归原作者，不复制原文段落。引用金句时注明作者与篇名。
