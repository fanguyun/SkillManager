## 3 证据分级怎么读

| 等级 | 含义 | 不能当成什么 |
|---|---|---|
| A | 有具体数字，来源是荟萃分析、大型队列或 RCT，能说出降了多少（HR、RR、百分比） | 不等于因果。A 级里既有随机分组的试验，也有只记录不分组的队列，后者分不清是这件事起作用还是做这件事的人本来更健康。看「收益」栏写没写"随机分成两组" |
| B | 有研究支持，但给不出确切数字，或只有小样本、单一研究 | 不等于"差不多可信"，只能说方向有依据 |
| C | 作者经验或普遍共识，没有直接文献 | 法律条款类条目给 C 级，通常是因为条文能逐字核对，但"照做能少多少损失"没有量化研究 |

**百分比的口径**是"比没做的人低几成"，不是"每一百人里少几个"。同样低 12%，本来风险就高的老人少掉的人数远多于年轻人。回答时必须带上"这数字说的是哪些人"。

## 4 性价比档不等于证据等级

性价比档（极高 / 高 / 一般）是作者按收益量级加三项成本合出来的**判断**，按书自己的标准只算 C 级。它可以和证据等级完全不一致：

- 带状疱疹疫苗有 97.2% 效力的三期 RCT（证据 A 级），但两针三四千元，性价比只算一般。
- 手机设锁屏密码、SIM 卡设 PIN 码（证据 C 级），性价比却是极高。

**"一般"不等于不该做**，全书条目都是建议做的，只是那一档得用户自己掂量花销。

## 6 怎么核对一条是否过期

```bash
cd "$BOOK" && git log -1 --format='%ci' -- book/19-在职离职和工伤.md   # 这节最后改动时间
git log --oneline -- book/05-不要浪费钱.md | head -10                  # 这节的改动记录
git pull --ff-only && grep -A3 '^### 16\. ' book/05-不要浪费钱.md      # 拉最新再看一遍
```

书里有专门的核实记录目录 `docs/核实记录/`，记录每条来源的核对过程与待核清单，回答"这数字可信吗"时可以去翻。
