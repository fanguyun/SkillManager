# 检索与排序手册

主流程执行时按需查。命令都在书仓库根目录（下称 `$BOOK`）运行。

## 1 取正文

```bash
# 首选：浅克隆，约 2.3 MB，几秒
git clone --depth 1 https://github.com/eternity4719/HowToLiveBetter.git "${TMPDIR:-/tmp}/hltb"
BOOK="${TMPDIR:-/tmp}/hltb"

# 兜底：单文件取（文件名含中文，直接写）
curl -fsSL --compressed "https://raw.githubusercontent.com/eternity4719/HowToLiveBetter/main/book/13-紧急情况.md"
```

判断本地模式：`README.md` 与 `book/01-不要早死.md` 同时存在即可。

更新本地副本（条目可能已改）：

```bash
cd "$BOOK" && git pull --ff-only
```

## 2 定位节

```bash
sed -n '/^## 这本书想回答的问题/,/^## 怎么读/p' README.md   # 问题 → 节 的映射表
ls book/                                                   # 文件名自带节号与节名
ls docs/                                                   # 长文
```

不要在 skill 里维护节清单，节会增删，一律现读这张表。

## 3 捞条目

```bash
# 列标题（带文件名和行号）
grep -rn '^### ' book/

# 按关键词过滤标题
grep -rn '^### ' book/ | grep -E '工伤|裁员'

# 正文搜索，带上下文
grep -rn -B2 -A10 '劳动仲裁' book/19-在职离职和工伤.md

# 按条号抽整条（注意节内条号，转义点号）
sed -n '/^### 16\. /,/^### 17\. /p' book/08-别把自己搭进去.md

# 抽整条但保留到下一节开头（防止最后一条丢）
awk '/^### 16\. /{f=1} f&&/^### 17\. /{exit} f' book/08-别把自己搭进去.md

# 全书搜，只要命中的节
grep -rln '违约金' book/
```

**必须整条读完，尤其「备注」栏**。备注里写着适用人群、争议、例外和门槛，只看标题会漏条件。

## 4 条目字段

```markdown
### 16. 借条写清这几项，转账备注写上借款
<!-- 成本标签: 钱=0 时间=少 毅力=否 收益=大 口径=金钱 -->
- 成本：
- 说人话：     ← 只用「收益」栏已有内容的通俗版，2 到 4 句
- 收益：       ← 全部原始数字、置信区间、人群、年份
- 证据等级：   A / B / C
- 来源：       ← 期刊 DOI 或官方文件链接
- 备注：       ← 争议、适用人群、例外；有争议时以「争议」开头
```

- **说人话** 是用来看懂的，**收益** 是用来核对的。两者冲突时以「收益」为准，且不许把说人话里没有的数字补进收益、也不许把收益里的数字省掉。
- 标题下一个 HTML 注释是成本标签，GitHub 不渲染，但用来筛选和排序。

## 5 成本标签与人群标签

```text
<!-- 成本标签: 钱=0|少|多 时间=少|中|多 毅力=否|些|是 收益=大|中|小 口径=死亡率|金钱|时间|自由 -->
```

| 字段 | 取值含义 |
|---|---|
| 钱 | `0` 不花钱或省钱；`少` 几十到几百元，或每月几十元内；`多` 上千元或长期显著支出 |
| 时间 | `少` 一次几分钟内或顺手；`中` 一次性数小时或每周小时级；`多` 每天持续占用 |
| 毅力 | `否` 做一次就完；`些` 改一个习惯或忍一点不适；`是` 长期对抗惯性 |
| 收益 | `大` / `中` / `小`，按各口径的既定界线机械套 |
| 口径 | `死亡率` / `金钱` / `时间` / `自由`，**四者不互相折算** |

可选 `人群=`，只有 7 个值：`怀孕`（含备孕、产后一年、哺乳）、`婴幼儿`（家有 3 岁以下）、`孩子`（家有 3 到 18 岁）、`老人`、`35岁`、`60岁`、`女性`。逗号是"或"，加号是"且"。**没有 `人群=` 就是人人适用**，绝大多数条目没有。

## 6 排序算法

正本在 `$BOOK/index.html`，现查：

```bash
grep -n 'COST_W = \|e\.ratio = ' index.html
```

当前口径（**以 index.html 现值为准，下面是 2026-10 的读数，仅供理解**）：

```text
成本分 cs = 钱(0:0 少:1 多:2) + 时间(少:0 中:1 多:2) + 毅力(否:0 些:1 是:2)

收益=大：cs==0 → 极高；cs<=2 → 高；否则 → 一般
收益=中：cs==0 → 高；否则 → 一般
收益=小：一律 → 一般
```

排序步骤：

1. 按性价比档：极高 > 高 > 一般。
2. 同档内证据等级 A > B > C。
3. 再按与用户处境的贴合度（人群标签是否命中、金额量级是否匹配、时效是否最新）。
4. **不同口径分开排**。换钱的和换寿命的各排各的，不能混成一张榜。

只拿到正文、没有 `index.html` 时，**不报性价比档**，把「收益量级 + 三项成本标签」原样列给用户。

## 7 快速自查某个主题的划算条目

```bash
# 某节里性价比极高候选（收益=大 且三项成本全为最低档）
grep -h -B1 '成本标签: 钱=0 时间=少 毅力=否 收益=大' book/01-不要早死.md

# 全书带人群标签的条目数（用于判断某个群体有多少可做项）
grep -h '成本标签' book/*.md | grep -c '人群='

# 某节条目总数
grep -c '^### ' book/19-在职离职和工伤.md
```

## 8 术语与长文

```bash
sed -n '/^## 读懂数字/,/^## 目录/p' README.md   # 41 条统计/法律术语解释
ls docs/                                        # 结婚划不划算、被裁了先做什么、刚确诊慢性病之后、换工作换城市之前……
```

用户看不懂 `HR`、`RR`、`95% CI`、`风险差`、`NOVA`、`LPR`、`认缴出资` 这类词时，直接查这张表，不要自己解释。

## 9 出处写法

统一写成「第 8 节第 17 条（借条和担保）」，括号里的词取自条目标题的前几个字，方便用户在检索页里搜到。

不要写「书上说」「研究表明」，也不要自己补 DOI、法条号或年份。条目「来源」栏里没有的链接一律不给。
