# 体检与指标追踪基线

> 以下为成年人体检的通用参考范围，不构成医疗建议。具体项目、频率与判读以医生意见和当地指南为准。

## 频率

| 人群 | 建议 |
| --- | --- |
| 18–39 岁，无慢病与家族史 | 每 1–2 年一次基础体检 |
| 40 岁以上 | 每年一次 |
| 有高血压、糖尿病、血脂异常等 | 按医嘱复查，频次高于常规 |
| 有明确家族史 | 相应项目提前开始并加密 |

## 基础项目

| 类别 | 项目 |
| --- | --- |
| 体格 | 身高、体重、BMI、腰围、血压 |
| 血液 | 血常规、空腹血糖、糖化血红蛋白、血脂四项 |
| 脏器 | 肝功能、肾功能、尿酸 |
| 尿液 | 尿常规 |
| 影像 | 胸部影像学检查（按需） |
| 心电 | 静息心电图（40 岁以上或有症状者） |

## 按年龄与性别延伸

| 项目 | 说明 |
| --- | --- |
| 乳腺筛查 | 女性按当地指南定期进行 |
| 宫颈筛查 | 女性按当地指南定期进行 |
| 前列腺相关 | 男性 50 岁起或按家族史提前 |
| 肠镜 | 一般 45–50 岁起，或有家族史时提前 |
| 骨密度 | 绝经后女性、长期使用激素者 |
| 甲状腺功能 | 有症状或家族史者 |
| 维生素 D | 少日照、深肤色、长期室内者 |
| 运动负荷试验 | 有心血管危险因素、计划开始高强度运动前 |

## 值得长期追踪的核心指标

这 6 项构成了代谢与心血管风险的主要图景，趋势比单次数值更有意义：

1. **血压** — 家庭自测，早晚各一次，记录 7 天取平均。
2. **腰围** — 比体重更能反映内脏脂肪变化。
3. **空腹血糖与糖化血红蛋白** — 前者看当下，后者看 2–3 个月平均。
4. **血脂四项** — 关注 LDL 与甘油三酯的走向。
5. **肝功能** — 反映代谢负担与饮酒影响。
6. **静息心率** — 兼作恢复状态与心肺适能的粗略指标。

## 记录建议

统一写入台账「表 4 体检指标趋势」，每次追加行不做覆盖。字段：日期、指标名、数值、单位、参考范围、机构、备注。

跨机构体检时，务必记录检查机构与所用参考范围，不同实验室的标准区间可能不同，直接比较数值会误判。

## 需要就医而不只是观察的情况

- 任何指标明显超出参考范围，或短期内变化幅度大。
- 出现不明原因的体重下降、持续疲劳、发热、疼痛。
- 血压持续 ≥ 140/90 mmHg，或家庭自测多次偏高。
- 空腹血糖持续偏高，或出现多饮、多尿、体重下降。
- 静息心电图异常、运动中出现胸痛或异常气短。

以上情况一律建议就医确认，不在对话中给出诊断。
