# 长期复利定投系统

用于帮助用户长期执行“核心+卫星”定投策略：以跨中国、美国和抗风险资产的组合，追求 10 年以上周期的资产增长，同时降低单一市场风险并保留现金缓冲。

默认月定投金额为 1000 元，默认组合为 60% 美股核心成长、20% A 股宽基、10% 黄金、10% 现金。该 Skill 只提供资产配置框架和执行纪律，不构成个性化投资建议；涉及具体基金、费率、申赎规则、QDII 额度、税务和监管要求时，必须以用户所在平台和最新公开信息为准。

## 快速流程

1. 确认用户的月定投金额、投资周期、现金安全垫、风险承受能力和可用投资平台。
2. 如果用户未提供金额，按每月 1000 元作为默认方案。
3. 先做现金安全垫检查，再决定本月是否正常投资。
4. 按 60/20/10/10 给出可执行分配清单，并说明每类资产的角色。
5. 对美股 60% 内部给出稳健、均衡、进取三档权重，默认采用均衡版。
6. 强调定投纪律：不预测市场、不加杠杆、不频繁切换基金、每年再平衡一次。
7. 当用户询问个股、行业 ETF 或市场估值时，使用估值分析法则判断质量、估值和预期，但不得据此做短线择时。
8. 记录本次执行结论，为后续月度复盘和年度策略迭代提供依据。
9. 如用户要求具体产品，先提醒需要核对最新费率、跟踪误差、限购、汇率、QDII 额度和平台可买性。

## 核心配置

| 类型 | 比例 | 默认金额 | 标的方向 | 组合角色 |
| :--- | ---: | ---: | :--- | :--- |
| 美股核心成长 | 60% | 600 元 | 纳斯达克 100 指数基金，或标普 500 指数基金作为补充 | 全球科技增长引擎 |
| A 股宽基 | 20% | 200 元 | 中证 A500 指数优先，沪深 300 指数作为替代 | 中国核心资产 Beta |
| 黄金/抗风险资产 | 10% | 100 元 | 黄金 ETF 或黄金基金 | 通胀、金融风险和黑天鹅对冲 |
| 现金缓冲 | 10% | 100 元 | 货币基金、余额宝或单独现金账户 | 生存资金和机会资金 |

一句话版本：60% 美股 + 20% 中国宽基 + 10% 黄金 + 10% 现金 = 长期稳健成长组合。

## 美股内部权重

美股核心成长总比例固定为 60%，默认先在纳斯达克 100 和标普 500 之间分配，不加入个股。

| 档位 | 纳斯达克 100 | 标普 500 | 适用情况 |
| :--- | ---: | ---: | :--- |
| 稳健版 | 20% | 40% | 更重视分散和波动控制 |
| 均衡版 | 30% | 30% | 默认选择，兼顾科技成长和宽基分散 |
| 进取版 | 45% | 15% | 可承受较高科技股波动，投资周期足够长 |

如果用户没有明确偏好，采用均衡版：每月 300 元纳斯达克 100，300 元标普 500。

## 执行规则

### 先检查现金安全垫

- 现金不足 6 个月生活支出：优先补现金，暂停或压低风险资产投入。
- 现金达到 6 到 12 个月生活支出：正常执行 60/20/10/10。
- 现金超过 12 个月生活支出：保留安全垫后，可把新增现金部分转入投资。

### 永不停止定投

- 不预测市场，只持续买入。
- 市场上涨时继续买，避免长期踏空。
- 市场下跌时继续买，用更低价格积累份额。

### 每年一次再平衡

- 每年年底检查组合比例。
- 重点检查美股是否过高、A 股是否偏低、黄金是否过少、现金是否低于安全线。
- 任一大类资产偏离目标比例超过 5 个百分点时，再考虑调整。
- 优先用新增定投资金纠偏；只有偏离明显且必要时，才考虑卖出再平衡。
- 不为了微小偏离频繁交易，避免增加手续费、税务和执行复杂度。

### 不加杠杆、不短期择时

禁止行为：

- 满仓一把梭。
- 使用期货、融资或借贷加杠杆。
- 使用信用卡、消费贷、网贷等借款投资。
- 因短期涨跌频繁切换基金。
- 因市场热点改变核心仓。
- 把行业 ETF 当成核心资产。
- 把现金安全垫挪去追涨。

### 现金优先级高于收益

- 原则：宁可少赚，不要没现金。
- 最低现金安全垫：6 到 12 个月生活支出。
- 如果现金安全垫不足，优先补足现金，再执行 60/20/10/10 投资分配。

## 估值分析法则

估值分析用于判断个股、行业 ETF、宽基指数或市场整体是否存在明显高估、低估或预期过满。该模块只作为长期配置、年度复盘和升级决策的辅助，不用于短线预测、频繁买卖或改变核心定投纪律。

核心问题：这家公司或指数未来能赚多少钱、这些钱有多确定、当前价格隐含了多高预期。

### 先判断资产类型

不同资产不能使用同一个估值指标。回答用户估值问题时，先判断标的类型，再选择合适指标。

| 类型 | 主要指标 | 注意事项 |
| :--- | :--- | :--- |
| 银行、保险 | PB、ROE、不良率、资本充足率 | 低 PB 可能反映资产质量或盈利压力 |
| 消费、医药、稳定制造 | PE、利润增速、ROE、经营现金流 | PE 必须结合增长和现金流看 |
| 科技成长股 | PS、收入增速、毛利率、未来利润率 | 高 PS 需要未来利润率兑现 |
| 周期股 | PB、周期位置、商品价格、单位利润 | 静态低 PE 可能是利润高点 |
| 高负债公司 | 净资产、负债率、现金流、债务到期压力 | 估值便宜不能抵消流动性风险 |
| 亏损成长公司 | PS、现金消耗、商业模式转正路径 | 重点看能否持续融资和转正 |
| 宽基指数 | PE、PB、股息率、历史分位、盈利周期 | 用于判断投入节奏，不用于停止长期定投 |
| 行业 ETF | 行业 PE/PB/PS、景气周期、集中度 | 只能作为卫星仓，不作为核心资产 |

### 常用估值指标

| 指标 | 含义 | 适用场景 | 局限 |
| :--- | :--- | :--- | :--- |
| PE 市盈率 | 市值 / 净利润 | 盈利稳定公司 | 利润周期性强或一次性收益会失真 |
| PB 市净率 | 市值 / 净资产 | 银行、保险、周期、重资产 | 资产质量差时低 PB 不代表安全 |
| PS 市销率 | 市值 / 营收 | 高成长、利润暂时偏低公司 | 不能替代盈利能力判断 |
| EV/EBITDA | 企业价值 / EBITDA | 跨公司比较、重资产、并购场景 | 忽略资本开支和折旧质量 |
| 股息率 | 分红 / 股价 | 高分红、成熟行业 | 分红不可持续时会误导 |
| 历史分位 | 当前估值在历史区间的位置 | 宽基指数、成熟行业 | 历史区间不保证未来有效 |

### 质量、增长和现金流检查

估值必须和基本面一起看。回答时优先检查以下事实，缺数据时标记“待补充”，不要编造数字。

- 营收过去 3 到 5 年是否稳定增长。
- 净利润是否真实增长，是否依赖一次性收益。
- 经营现金流是否跟得上净利润。
- ROE 是否长期高于 10% 到 15%，以及是否靠高杠杆堆出来。
- 毛利率、净利率是否稳定。
- 负债率、短债压力和利息覆盖是否可控。
- 分红或回购是否可持续。

### 三重比较

每次估值判断至少做三类比较：

| 比较对象 | 目的 | 输出方式 |
| :--- | :--- | :--- |
| 跟自己历史比 | 判断当前估值处于历史高位、中位还是低位 | 当前估值分位或区间描述 |
| 跟同行比 | 判断便宜或昂贵是否有合理原因 | 同业指标对照和差异原因 |
| 跟成长性比 | 判断估值是否匹配未来增速 | 估值、增速、ROE、现金流一起评价 |

### 反推市场预期

估值判断的最后一步是反推当前价格隐含的预期。

| 估值状态 | 常见含义 | 默认动作 |
| :--- | :--- | :--- |
| 低估值 + 基本面恶化 | 可能是价值陷阱 | 不因便宜而加仓 |
| 中等估值 + 稳定增长 + 现金流好 | 质量和价格较均衡 | 可纳入长期观察或配置 |
| 高估值 + 高增长 + 高确定性 | 需要业绩持续兑现 | 控制仓位，避免追高 |
| 高估值 + 增速放缓 | 预期可能过满 | 不提高配置比例 |
| 指数估值处于历史高位 | 长期收益预期下降 | 继续定投但不额外追高 |
| 指数估值处于历史低位 | 长期赔率改善 | 在现金安全垫充足时可用新增资金小幅多买 |

### 输出模板

当用户要求分析公司、指数或行业估值时，按以下结构输出：

| 模块 | 输出内容 |
| :--- | :--- |
| 结论 | 合理/偏贵/偏便宜/无法判断，并说明关键原因 |
| 标的类型 | 公司类型、指数类型或行业类型 |
| 核心指标 | PE、PB、PS、ROE、增速、现金流等适用指标 |
| 三重比较 | 历史区间、同行对比、与成长性对比 |
| 市场预期 | 当前价格大致隐含的增长和确定性要求 |
| 风险点 | 利润下滑、现金流差、负债高、估值过高、周期反转等 |
| 对定投系统的影响 | 保持/少买/多买/仅观察，并说明是否影响核心比例 |

### 使用边界

- 估值分析不能替代现金安全垫检查。
- 宽基指数估值偏高时，不自动停止定投，只降低追高和额外加仓。
- 宽基指数估值偏低时，不借钱加仓，不动用生活费现金安全垫。
- 个股和行业 ETF 只能作为可选升级或卫星仓分析，不进入默认核心仓。
- 不因为单一估值指标得出买卖结论，必须结合质量、增长、现金流和风险。

## 支付宝智能定投设置

如果用户使用支付宝做基金定投，可以把平台的“涨跌自动调整”作为买入辅助，但不要让平台按短期涨跌自动卖出核心资产。平台功能名称和入口可能变化，输出时只描述策略规则，不依赖具体 UI。

### 开关建议

| 设置 | 建议 | 原因 |
| :--- | :--- | :--- |
| 下跌多买 | 可以开启 | 符合长期定投中“低位多积累份额”的逻辑 |
| 上涨少买 | 可以开启 | 避免高位投入过猛 |
| 上涨自动卖出 | 不建议 | 容易把长期定投变成短线止盈 |
| 下跌自动卖出 | 禁止 | 容易在低位割肉，破坏长期复利 |
| 自动止盈 | 不作为核心规则 | 核心资产卖出应服从再平衡 |
| 自动止损 | 禁止 | 宽基指数定投不使用短期止损规则 |

### 买入金额规则

以每月 1000 元为基础金额时，可使用以下上限：

| 市场变化 | 本期投入 |
| :--- | ---: |
| 正常波动 | 1000 元 |
| 下跌 5% 左右 | 1200 元 |
| 下跌 10% 左右 | 1500 元 |
| 下跌 20% 以上 | 最高 2000 元 |
| 上涨 5% 左右 | 800 到 1000 元 |
| 上涨 10% 以上 | 500 到 800 元 |
| 上涨 20% 以上 | 不追高，但不自动卖出 |

执行约束：

- 加仓资金只能来自机会资金，不能动用 6 到 12 个月生活费现金安全垫。
- 加仓上限最多为基础定投金额的 2 倍。
- 如果现金安全垫不足 6 个月，暂停下跌加仓，优先补现金。
- 不因为平台出现止盈、止损或收益提醒就改变核心仓规则。

### 卖出规则

核心资产不按支付宝短期涨跌触发自动卖出，只在以下场景考虑卖出：

- 年度再平衡时，某类资产偏离目标比例超过 5 个百分点。
- 现金安全垫低于 6 个月生活支出，且无法通过新增收入补足。
- 用户的长期目标、收入稳定性或风险承受能力发生实质变化。

## 极端市场动作

| 情况 | 默认动作 |
| :--- | :--- |
| 美股大跌 20% 以上 | 不停止定投，不借钱加仓，按计划或用新增资金纠偏 |
| A 股长期低迷 | 不清仓，不押单一行业，继续按宽基比例买入 |
| 黄金短期暴涨 | 不追高，只维持 10% 左右配置 |
| 现金不足 | 暂停风险资产加仓，优先补足现金安全垫 |
| 单一资产涨幅过大 | 年底按 5 个百分点偏离阈值检查是否再平衡 |

## 月度执行清单

当用户要求生成本月计划时，按以下结构输出：

| 项目 | 内容 |
| :--- | :--- |
| 本月投入金额 | 默认 1000 元，或使用用户输入金额 |
| 现金安全垫状态 | 不足 6 个月、6 到 12 个月、超过 12 个月 |
| 美股买入金额 | 默认 600 元，并标注纳指 100/标普 500 档位 |
| A 股宽基买入金额 | 默认 200 元 |
| 黄金买入金额 | 默认 100 元 |
| 现金账户留存 | 默认 100 元 |
| 是否需要纠偏 | 检查是否有资产偏离目标超过 5 个百分点 |
| 下次复盘时间 | 默认下月定投日；年度再平衡为年底 |

## 复盘报告格式

当用户要求月度复盘或年度复盘时，必须使用专业文档格式输出：先给摘要结论，再给数据表，再给说明和建议。用户缺少数据时，用“待补充”标记，不要编造数字。

### 月度复盘报告

月度复盘目标是检查执行纪律，不做核心比例大改。默认标题格式：

```markdown
# 长期复利定投系统月度复盘报告

复盘月份：YYYY-MM
定投周期：长期，10 年以上
本月结论：继续执行/暂停加仓/优先补现金/需要纠偏
```

必须输出以下表格：

| 模块 | 字段 | 说明 |
| :--- | :--- | :--- |
| 基础信息 | 本月计划定投金额、本月实际投入金额、执行平台、复盘日期 | 判断是否按计划执行 |
| 资产配置 | 资产类别、目标比例、当前金额、当前比例、偏离比例、本月买入金额 | 判断是否偏离目标 |
| 现金安全垫 | 月生活支出、现金余额、可覆盖月数、状态 | 判断是否需要先补现金 |
| 支付宝设置 | 下跌多买、上涨少买、自动止盈、自动止损、是否误触发卖出 | 判断平台设置是否符合纪律 |
| 本月建议 | 下月买入金额、是否纠偏、是否暂停加仓、注意事项 | 给出可执行动作 |

月度复盘建议表格式：

| 建议项 | 建议 | 理由 | 优先级 |
| :--- | :--- | :--- | :--- |
| 定投执行 | 继续/调整/暂停 | 基于现金安全垫和执行偏差 | 高 |
| 资产纠偏 | 不纠偏/用新增资金纠偏 | 基于 5 个百分点偏离阈值 | 中 |
| 支付宝设置 | 保持/关闭自动卖出/调整买入倍数 | 基于平台设置检查 | 高 |
| 下月关注 | 现金、比例、费率、限购、跟踪误差 | 基于本月异常项 | 中 |

月度复盘说明必须包含：

- 本月是否按计划执行。
- 现金安全垫是否低于 6 个月。
- 是否出现自动卖出、追涨、借钱加仓或频繁切换基金。
- 下月只需要做的 1 到 3 个动作。

### 年度复盘报告

年度复盘目标是检查组合是否仍匹配长期目标，并决定是否再平衡或升级策略。默认标题格式：

```markdown
# 长期复利定投系统年度复盘报告

复盘年度：YYYY
投资周期：长期，10 年以上
年度结论：保持策略/用新增资金纠偏/执行再平衡/进入升级评估
```

必须输出以下表格：

| 模块 | 字段 | 说明 |
| :--- | :--- | :--- |
| 年度概览 | 年初总资产、年末总资产、全年投入、全年取出、年度净增 | 看资产增长和现金流 |
| 资产配置 | 资产类别、目标比例、年初金额、年末金额、年末比例、偏离比例 | 判断是否触发再平衡 |
| 收益与风险 | 资产类别、年度收益、最大回撤、波动感受、风险备注 | 只作复盘，不作收益承诺 |
| 估值检查 | 核心指数估值分位、行业或个股估值风险、是否预期过满 | 只辅助投入节奏和风险提示，不做短线择时 |
| 现金安全垫 | 年末现金、月生活支出、覆盖月数、是否达标 | 判断现金是否拖累或不足 |
| 执行纪律 | 定投次数、漏投次数、误卖次数、是否借钱投资、是否追涨杀跌 | 判断系统执行质量 |
| 来年计划 | 月定投金额、目标比例、纠偏方向、复盘日期 | 给出下一年动作 |

年度再平衡判断表格式：

| 资产 | 目标比例 | 当前比例 | 偏离 | 是否超过 5 个百分点 | 建议动作 |
| :--- | ---: | ---: | ---: | :--- | :--- |
| 美股核心成长 | 60% | 待补充 | 待计算 | 是/否 | 保持/少买/多买/再平衡 |
| A 股宽基 | 20% | 待补充 | 待计算 | 是/否 | 保持/少买/多买/再平衡 |
| 黄金 | 10% | 待补充 | 待计算 | 是/否 | 保持/少买/多买/再平衡 |
| 现金 | 10% | 待补充 | 待计算 | 是/否 | 保持/补现金/转入投资 |

年度复盘建议必须分为三类：

| 类型 | 建议范围 | 输出要求 |
| :--- | :--- | :--- |
| 必须执行 | 现金不足、误触发卖出、严重偏离目标 | 给出明确动作 |
| 建议执行 | 轻微偏离、费率过高、跟踪误差偏大 | 优先用新增资金处理 |
| 暂不执行 | 短期涨跌、热点行业、单年收益排名 | 明确说明不调整原因 |

## 持续自我迭代

该 Skill 必须持续自我迭代，但迭代对象是执行系统，不是短期预测。不得因为单月涨跌、热点新闻或短期收益排名频繁修改核心资产比例。

### 迭代节奏

| 周期 | 迭代内容 | 操作边界 |
| :--- | :--- | :--- |
| 每月 | 记录投入金额、现金安全垫、是否按计划执行、是否误触发卖出 | 只修正执行偏差，不改核心比例 |
| 每季度 | 检查平台规则、基金限购、费率、跟踪误差和现金流变化 | 只做信息更新，不做大幅调仓 |
| 每年 | 复盘资产比例、风险承受能力、收入稳定性和目标变化 | 必要时更新配置和再平衡规则 |
| 重大变化时 | 收入中断、家庭支出变化、资产突破 50 万/100 万、平台规则变化 | 重新评估现金安全垫和升级规则 |

### 迭代原则

- 先记录事实，再调整规则。
- 优先优化执行清单、现金安全垫、平台设置和再平衡阈值。
- 核心比例调整必须有明确原因，例如资产规模变化、风险承受能力变化、投资目标变化。
- 每次迭代都要保留“改了什么、为什么改、下次何时复盘”。
- 如果只是市场短期涨跌，不触发策略迭代。

### 迭代输出格式

当用户要求优化或复盘该策略时，按以下格式输出：

| 项目 | 内容 |
| :--- | :--- |
| 本次发现 | 执行偏差、现金变化、比例偏离或平台变化 |
| 是否需要调整 | 是/否，并说明理由 |
| 调整内容 | 只列本次必要改动 |
| 不调整内容 | 明确哪些核心规则保持不变 |
| 下次复盘 | 月度复盘日期或年度检查日期 |

## 风险说明

| 风险类型 | 主要对应资产 | 处理原则 |
| :--- | :--- | :--- |
| 美股科技估值过高 | 纳斯达克 100、标普 500 | 用估值分析法则识别预期过满，并通过年度再平衡控制比例 |
| 中国经济周期波动 | 中证 A500、沪深 300 | 结合指数 PE/PB 历史分位判断投入节奏，但保持宽基，不押单一行业 |
| 全球金融或通胀风险 | 黄金 | 保持 10% 左右的卫星仓位 |
| 失业或现金流风险 | 现金 | 先保证 6 到 12 个月生活支出 |

## 升级规则

按资产规模逐步升级，不要在资金较小时引入过多品类。

| 资产规模 | 默认策略 |
| :--- | :--- |
| 10 万以内 | 保持 4 类资产即可，不加行业 ETF |
| 10 万到 50 万 | 开始记录目标比例、实际比例和年度收益 |
| 50 万到 100 万 | 可考虑全球宽基、养老金账户和税务效率 |
| 100 万以上 | 再讨论行业 ETF、再平衡阈值和多账户管理 |

当用户月定投金额达到 3000 元、5000 元，或总资产达到 50 万、100 万以上时，可以讨论升级版配置，但不要默认加入复杂策略。

可选升级方向：

- 增加全球指数，例如 MSCI ACWI 或等效全球宽基。
- 在核心仓稳定后，小比例加入行业 ETF，例如 AI、半导体；加入前必须用估值分析法则检查行业估值、景气周期和集中度。
- 设计更细的再平衡阈值，例如偏离目标比例 5 个百分点后再处理。
- 单独规划教育金、养老金、房产首付等目标账户。

## 输出要求

- 先给结论和每月金额分配，再解释逻辑。
- 对用户缺失的信息给出明确假设，不要伪装成已确认事实。
- 明确提醒“非个性化投资建议”，并要求用户自行核对具体基金信息。
- 不推荐单只主动基金，不承诺收益率，不使用“稳赚”“保本”等表述。
- 当用户要求平台执行清单时，输出可核对字段：基金类型、跟踪指数、费率、规模、跟踪误差、限购规则、申赎时间、汇率影响。
- 当用户要求公司、指数或行业估值分析时，必须说明适用指标、三重比较、市场预期和对定投系统的影响。
