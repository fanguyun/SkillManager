# Autoregulation: Reps to Failure (RTF)

Source: SBS Program Bundle by Greg Nuckols
Programs: SBS Strength Program RTF, SBS Strength Program RTF LF, SBS Hypertrophy Template, SBS Hypertrophy Template LF

## How It Works

In the RTF method, you perform a fixed number of normal sets at prescribed reps, then take the **last set to failure**. Your TM adjusts based on how your actual reps compare to the rep target for that intensity.

### Workout Flow

1. Look up today's prescribed sets, normal set reps, and last set rep target
2. Perform all normal sets at the prescribed reps (e.g., 4 sets of 5)
3. On the **last set, go to failure** (or technical failure)
4. Log the number of reps completed on the last set

### TM Adjustment Scale (Same for Strength RTF and Hypertrophy)

| Condition | TM Change | Default |
|-----------|-----------|---------|
| Reps < target by 2+ | Large decrease | −5% |
| Reps < target by 1 | Small decrease | −2% |
| Reps = target | No change | 0% |
| Reps > target by 1 | Small increase | +0.5% |
| Reps > target by 2 | Increase | +1% |
| Reps > target by 3 | Increase | +1.5% |
| Reps > target by 4 | Increase | +2% |
| Reps > target by 5+ | Large increase | +3% |

## Hypertrophy Template Specifics

**Default sets**: 4 (3 normal + 1 to failure)

The Hypertrophy Template uses the same RTF autoregulation method but with key differences:
- Higher rep targets across the board
- Normal set reps derived from failure targets: `Normal reps = MROUND(Last_Set_Target × 0.8, 1)`
- Lower intensity ceiling (82.5% max vs 95%)
- More volume per set (higher reps) but fewer total sets

## Defining "Failure"

Three acceptable definitions — pick one and apply consistently:
1. **True failure**: Go until you actually miss a rep
2. **0 RIR**: Stop when you know you couldn't complete another rep (recommended for most)
3. **Technical failure**: Stop when form starts to break down

Nuckols generally recommends against true failure. 0 RIR is fine for most people unless form degrades significantly when grinding.

## Customization

### Sets Per Exercise
- **Strength RTF**: Default 5 (4 normal + 1 failure). Adjust per-exercise based on recoverability.
- **Hypertrophy**: Default 4 (3 normal + 1 failure). This program is demanding — Nuckols recommends starting with conservative TMs.

### Rep Targets (Per Exercise)
- Good strength endurance: increase rep targets
- Poor strength endurance: decrease rep targets
- Strength RTF normal set rep targets are intentionally low (room for quality sets)
- Hypertrophy normal set rep targets are relatively high (every set should be reasonably challenging)

### TM Adjustment Percentages
Same customization rules as other programs. Advanced lifters may reduce positive adjustments; returning lifters may increase them temporarily.

## Effort Requirement

Don't sandbag the failure set. Don't cheat range of motion to hit more reps. If you can legitimately beat the rep target, do it — that's how TMs progress. The program only works if you actually push on the AMRAP set.

## Example Workout (Strength RTF)

Exercise: Squat, Week 1
- Intensity: 70% TM → Working weight
- Normal sets: 4 × 5 reps
- Last set rep target: 10

You do 4 sets of 5, then go to failure on set 5. You get 12 reps.
12 − 10 = 2 above target → TM increases by +1%

If you got 8 reps (2 below target) → TM decreases by −5%.
If you got exactly 10 → TM unchanged.

## Example Workout (Hypertrophy)

Exercise: Squat, Week 1
- Intensity: 70% TM → Working weight
- Normal sets: 3 × 10 reps
- Last set rep target: 12

You do 3 sets of 10, then go to failure on set 4. You get 14 reps.
14 − 12 = 2 above target → TM increases by +1%
