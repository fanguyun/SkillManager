## TM Adjustment Scales

### Set Threshold (SBS Strength Program)

| Condition | Default |
|-----------|---------|
| Sets < lower threshold | −5% |
| Lower ≤ sets ≤ upper threshold | 0% |
| Sets > upper threshold | +2% |

Default lower = 4, upper = 6.

### Last Set RIR / RTF / Hypertrophy (8-level scale)

| Level | Condition (RIR) | Condition (RTF) | Default |
|-------|----------------|-----------------|---------|
| 1 | Failed to complete sets | Failed to complete sets | −5% |
| 2 | RIR < target | Reps < target by 1 | −2% |
| 3 | RIR = target | Reps = target | 0% |
| 4 | RIR = target + 1 | Reps = target + 1 | +0.5% |
| 5 | RIR = target + 2 | Reps = target + 2 | +1% |
| 6 | RIR = target + 3 | Reps = target + 3 | +1.5% |
| 7 | RIR = target + 4 | Reps = target + 4 | +2% |
| 8 | RIR ≥ target + 5 | Reps ≥ target + 5 | +3% |

### Novice LP (8-level scale, more aggressive)

| Level | Condition | Default |
|-------|-----------|---------|
| 1 | Failed to complete sets | −5% |
| 2 | Completed sets, RIR below target | −2% |
| 3 | RIR = target (0) | 0% |
| 4 | RIR = 1 | +1% |
| 5 | RIR = 2 | +3% |
| 6 | RIR = 3 | +5% |
| 7 | RIR = 4 | +5% |
| 8 | RIR ≥ 5 | +5% |

Much more aggressive positive adjustments — appropriate for novice lifters making rapid progress.
