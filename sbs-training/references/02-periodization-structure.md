# Periodization Structure

Source: SBS Program Bundle by Greg Nuckols

## 21-Week Macrocycle (All Intermediate Programs)

The SBS Strength, Last Set RIR, RTF, and Hypertrophy programs all use a 21-week macrocycle divided into three 7-week blocks:

```
Block 1 (Weeks 1–7):  Lightest intensity, highest reps per set
Block 2 (Weeks 8–14): Moderate intensity, moderate reps
Block 3 (Weeks 15–21): Heaviest intensity, lowest reps per set
```

This is a **block periodization** approach — each block increases intensity while decreasing rep targets.

## Wave Loading Within Blocks

Each 7-week block uses **weekly undulating wave loading**:
- Two 3-week ascending waves, followed by a deload
- Pattern within each block: up, up, up, slight reset, up, up, deload

### Strength Programs — Main Lift Intensity Pattern

| | Wave 1 | | | Wave 2 | | | Deload |
|---|---|---|---|---|---|---|---|
| Block 1 | 70% | 75% | 80% | 72.5% | 77.5% | 82.5% | 60% |
| Block 2 | 75% | 80% | 85% | 77.5% | 82.5% | 87.5% | 60% |
| Block 3 | 80% | 85% | 90% | 85% | 90% | 95% | 60% |

### Hypertrophy Template — Main Lift Intensity Pattern

| | Wave 1 | | | Wave 2 | | | Deload |
|---|---|---|---|---|---|---|---|
| Block 1 | 70% | 72.5% | 75% | 72.5% | 75% | 77.5% | 60% |
| Block 2 | 72.5% | 75% | 77.5% | 75% | 77.5% | 80% | 60% |
| Block 3 | 75% | 77.5% | 80% | 77.5% | 80% | 82.5% | 60% |

Key difference: Hypertrophy intensity increases in 2.5% steps and caps at 82.5%, while Strength uses 5% steps and peaks at 95%.

## Daily Undulating Programming

Within each session, **main (core) lifts are trained at higher intensity than auxiliary lifts**:
- Strength programs: auxiliary intensity = main intensity − 10%
- Hypertrophy template: auxiliary intensity = main intensity − 5%

This creates intensity variation within each training day.

## Deload Weeks (Weeks 7, 14, 21)

Deload weeks are "hard coded" — performance is not tracked and TM does not change.

| Program | Deload Sets | Deload Intensity | TM Change |
|---------|-------------|------------------|-----------|
| Strength (Set Threshold) | 4–6 | 60% (main), 50% (aux) | None |
| Last Set RIR | 5 | 60% (main), 50% (aux) | None |
| RTF (Strength) | 5 | 60% (main), 50% (aux) | None |
| Hypertrophy | 4 | 60% (main), 55% (aux) | None |

During deloads:
- No RIR cutoff / RIR target / rep target applies
- Just complete the prescribed sets at the listed weight and move on
- Take it easier with upper back training and accessories too

## Late-Program Guidance (Weeks 18–21)

The final block pushes intensity very high (85–95% for strength programs). Some lifters may find weeks 19–20 very demanding.

**Week 20 (95% TM singles) specifically**: If this feels too heavy, go off-script. Work up to a "conservative max" — a weight you're 100% sure you can hit. If you've competed in powerlifting, think first-to-second attempt territory.

The goal of weeks 18–20 is to **be ready for max testing**, not to grind yourself into the ground. Don't worry about the autoregulation feedback during these weeks — if the sheet bumps your TM down, it won't impact anything since the program is ending.

## Testing Maxes

Test 1RMs either:
- Near the end of week 21
- Near the start of week 22

## Re-Running the Program

After completing all 21 weeks:
- Download a fresh copy, plug in new maxes, and go again
- Or if you only want to run 14 weeks, plug week-14 TMs into a fresh copy
- These programs are designed to be run repeatedly long-term

## Novice Programs — No Periodization

The Linear Progression and Novice Hypertrophy programs are **open-ended** with no block structure:
- Same intensity every week (LP: 87.5% main / 82.5% aux1 / 75% aux2)
- Progression is purely performance-driven (TM increases when you exceed targets)
- No deload weeks built in
- Run until you can no longer add weight weekly, then transition to an intermediate program

## Adding Extra Deloads

If you get worn down by the constant high-intensity training in Block 3 (especially weeks 15–20 in the strength programs, which are 85%+ for 5 straight weeks), consider inserting a deload between weeks 17 and 18.

## Work Capacity Block Variant

To build work capacity: run the Set Threshold program (program #1) with very conservative TMs (~88% of normal). Run Block 1 twice. During the first run, you'll be able to do many sets per exercise, building work capacity. By the end, TMs will naturally catch up to where they should be.
