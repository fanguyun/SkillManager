# Autoregulation: Last Set RIR

Source: SBS Program Bundle by Greg Nuckols
Programs: SBS Strength Program Last Set RIR, SBS Strength Program Last Set RIR LF

## How It Works

In the Last Set RIR method, you perform a fixed number of sets at prescribed reps, then rate your RIR (reps in reserve) on the final set. Your TM adjusts based on how your actual RIR compares to the target RIR.

### Workout Flow

1. Look up today's prescribed sets, reps, and RIR target
2. Perform all prescribed sets at the prescribed reps
3. After the **last rep of the last set**, estimate your RIR
4. Log: sets completed + RIR on last set

### TM Adjustment Scale

| Condition | TM Change | Default |
|-----------|-----------|---------|
| Failed to complete all prescribed sets | Large decrease | −5% |
| Completed sets but RIR < target | Small decrease | −2% |
| RIR = target | No change | 0% |
| RIR = target + 1 | Small increase | +0.5% |
| RIR = target + 2 | Increase | +1% |
| RIR = target + 3 | Increase | +1.5% |
| RIR = target + 4 | Increase | +2% |
| RIR ≥ target + 5 | Large increase | +3% |

**Default sets per exercise**: 5

### RIR Targets

RIR targets vary by intensity. Higher targets at lower intensities (to limit fatigue):

| %TM | RIR Target |
|-----|-----------|
| 50–72.5% | 3 |
| 75–82.5% | 2 |
| 85–97.5% | 1 |
| 100% | 0 |

All lifts use the same default targets. Customize per-exercise if needed.

### Rep Targets (Same as Strength Program)

| %TM | Reps |
|-----|------|
| 50–57.5% | 8 |
| 60–62.5% | 7 |
| 65–67.5% | 6 |
| 70–72.5% | 5 |
| 75–77.5% | 4 |
| 80–82.5% | 3 |
| 85–87.5% | 2 |
| 90–100% | 1 |

## RIR Estimation Guidance

Most lifters can accurately estimate RIR within 2–3 reps of failure. Beyond ~4–5 RIR, accuracy drops significantly.

**If a workout is very easy (5+ RIR)**: Don't stress about the exact number. Your TM clearly needs to go up substantially, so even an imprecise estimate will push it in the right direction. The net effect of underestimating might be an extra week or two for TMs to reach appropriate levels.

**Checking your estimates**: Occasionally take a set to actual failure to calibrate your RIR sense. If you thought you had 3 RIR and only got 1 more rep (or got 5+ more), your estimation needs work.

**If you can't estimate RIR confidently**: Continue the last set past the prescribed reps until you reach an RIR you ARE confident about. If prescribed reps = 5, you have lots of RIR at rep 5, and you're only confident at 3 RIR or fewer, keep going until 3 RIR. If you stop at rep 9, your effective RIR was 7 (4 extra reps + 3 RIR at the stop point). Report 7 in the spreadsheet.

## Customization

### Sets Per Exercise
- More recoverable lifts (OHP): increase to 6–7
- Very fatiguing lifts (Deadlift): decrease to 3–4

### TM Adjustment Percentages
- Advanced lifters: reduce positive adjustments (slower progression)
- Novice/returning lifters: increase positive adjustments temporarily
- Decrease percentages must be entered as negative numbers

### RIR Targets
- If a lift thrives near failure: decrease targets (more aggressive training)
- If you respond poorly to close-to-failure work: increase targets

## RIR vs RTF Correspondence

The Last Set RIR and RTF programs are designed to provide similar training stress. The RIR targets are intentionally set LOWER than what the RTF rep targets would imply. For example, if RTF targets 10 reps and you do 5 normal reps, that implies ~5 RIR, but the RIR target is 3.

Reason: With a lower RIR threshold for load increases, TMs advance slightly faster in the Last Set RIR version, leading to slightly heavier working weights. The result is 5 submaximal sets with heavier weight (Last Set RIR) vs. 4 submaximal + 1 failure set with lighter weight (RTF) — similar overall training stress.

## Example Workout

Exercise: Squat, Week 1
- Intensity: 70% TM → Working weight calculated via formula
- Prescribed: 5 sets of 5 reps
- RIR target: 3

You do 5 sets of 5 reps. After the last rep of set 5, you estimate you could have done 6 more reps → actual RIR = 6.

6 − 3 = 3 above target → TM increases by +1.5%

If actual RIR was 2 (below target of 3) → TM decreases by −2%.
If actual RIR was 3 (matches target) → TM unchanged.
If you only completed 4 of 5 sets → TM decreases by −5%.
