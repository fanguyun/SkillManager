# Tips and Recommendations

Source: SBS Program Bundle by Greg Nuckols

## Best Results Data

Based on data Nuckols has collected from program users:

1. **RTF template has produced the best results**, followed closely by the Hypertrophy Template
2. **People who regularly do overwarm singles before work sets get better strength gains** (whether or not they use the single @8 function to adjust TM)

**Recommendation**: If debating which program to run, choose RTF or Hypertrophy Template with overwarm singles.

## Effort Requirements

The program only works if you genuinely push yourself. Key points:

- **Don't treat targets as prescriptions** — they're landmarks. If you can do more, do more.
- Don't lie about RIR to inflate TM faster, but also don't sandbag.
- Don't cheat range of motion on failure sets to hit more reps.
- If you never exceed targets, your TM will never change and you won't get stronger.

Specific per-program:
- **Set Threshold**: Don't stop at 4–6 sets if you can do more below the RIR cutoff
- **Last Set RIR**: Don't always report exactly the target RIR if you actually had more
- **RTF**: Don't stop at the rep target if you can do more reps

## Starting Training Maxes

- Conservative or true 1RM — either works. The program self-corrects within 3–4 weeks.
- For **Hypertrophy Template**: Start with really conservative TMs (85–90% of true max) if you're not used to high-rep training.
- A rough estimate is fine for auxiliaries you don't know your max for.

## Rest Periods

- Minimum **2–3 minutes** between sets recommended
- Very long rest intervals let you do more sets in the Set Threshold program, which can inflate TM. If things are easy after set 6, shorten rest intervals rather than doing unlimited sets.
- There's no strict prescription — rest periods are what you make them.

## Supersetting

If pressed for time, supersetting is acceptable with these pairings:
- **Agonist/antagonist**: bench + rows
- **Unrelated motor patterns**: OHP + deadlift

**Avoid** supersetting:
- Two pressing exercises together
- Deadlift + squat exercises
- Core lifts with accessories for the same muscle group

Results will likely be slightly better without supersetting, but supersetting is a good time-efficiency option.

## Overwarm Singles

- Recommended especially for main lifts during Block 1
- During Block 1, you can do the single without logging it (just for neural practice with heavy loads)
- To use single @8 without adjusting TM: just don't enter the weight in the "single @8" cell
- If you want to use 85–93% singles without the autoregulation function, just do them and don't log them
- Always doing singles for all auxiliaries may be overkill

## Upper Back Training

- Dedicated slot in every session in most programs
- Minimum 2–3x/week recommended
- With higher frequency programs (5x–6x), you don't need to train upper back every session
- No pre-built progression — just aim to improve over time

## Accessories

- Be judicious — don't fill all slots just because they exist
- Choose for specific weak points or undertrained muscle groups
- No pre-built progression (except in Program Builder)
- Previous session's data auto-fills as targets to beat

## Switching Between Programs

If you want to change program versions mid-cycle:
1. Set up Quick Setup and Setup tabs in the new program
2. Find your current TMs for each exercise
3. Enter those TMs on the current week of the new program
4. Continue as if you'd been doing it all along

In the **Program Builder**, it's even easier — just cut/paste the old progression out and the new one in.

## Changing Auxiliary Lifts

1. Change the exercise on Quick Setup
2. Do NOT change TM on Quick Setup
3. Expand the hidden TM row on the tracking sheet
4. Enter new exercise's TM on the week you're swapping
5. Keep each auxiliary for at least one full 7-week block

In the Program Builder: just cut/paste old lift out, new lift in.

## Using Wrong Weights

If you accidentally used the wrong weight:
- Don't edit the weight in the spreadsheet (it won't recalculate TM correctly)
- Make a note in the "notes" column
- **Too light**: Fill in spreadsheet as if TM should stay the same
- **Too heavy + missed targets**: Fill in as if TM should stay the same
- **Too heavy + still hit/exceeded targets**: Fill in to increase TM by one step

## Short on Gym Time

If you have to cut a workout short, fill in the spreadsheet as if you met (but didn't exceed) your targets. The spreadsheet doesn't know if you did fewer sets due to poor performance or time constraints. Make a note for yourself about actual performance.

## Caloric Context

The program accommodates any caloric context:
- **Caloric surplus**: Beat targets more often → faster TM progression
- **Caloric deficit**: Beat targets less often → slower progression (or slight regression, with automatic TM reduction)
- **Stress/poor sleep**: Same principle — the autoregulation adapts to your current state

## Decimal/Comma Locale

If you're in a country using commas for decimals (2,5 instead of 2.5), the spreadsheet may break with decimal rounding increments. Replace periods with commas (2,5 or 0,5).

## Adding Extra Accessories

Insert a new row under the last accessory row to add more than the default 3 per day.

## Re-Running the Program

- Download a fresh copy with new maxes after completing 21 weeks
- Or plug week-14 TMs into a fresh copy if only doing 14 weeks
- These programs are designed for long-term repeated use
- Test 1RMs at end of week 21 or start of week 22

## Additional Deload Option

If Block 3 intensity (85%+ for 5 straight weeks in strength programs) is too demanding, insert an extra deload between weeks 17 and 18.

## Work Capacity Block

Use the Set Threshold program with conservative TMs (~88% of normal). Run Block 1 twice. During the first run, you'll complete many sets (building work capacity). By the end, TMs naturally catch up to appropriate levels.

## Sport-Specific Training

For non-strength sports (football, basketball, soccer, etc.):
- **Last Set RIR** version is a good option
- Bump RIR targets up by 1–2 (e.g., from 2 to 3–4)
- Staying further from failure may aid power/velocity development
- Loads should still be heavy enough to build strength

## Mobile Use

If using spreadsheets on mobile, hide weeks you're not currently using to minimize scrolling.

## Main Lift Flexibility

You can customize main lifts freely:
- Powerlifters: 4 bench variations, no OHP
- One deadlift session per week: sub auxiliary deadlift for more squatting or drop it
- Weighted pull-ups as a core lift: include bodyweight + added weight for 1RM and working weights
