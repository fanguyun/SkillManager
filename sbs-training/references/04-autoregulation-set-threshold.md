# Autoregulation: Set Threshold

Source: SBS Program Bundle by Greg Nuckols
Programs: SBS Strength Program, SBS Strength Program LF

## How It Works

In the Set Threshold method, you perform sets of a prescribed number of reps until you reach an RIR (reps in reserve) cutoff. Then you count how many sets you completed and compare to your set threshold range.

### Workout Flow

1. Look up today's prescribed reps and RIR cutoff for each exercise
2. Perform sets of the prescribed reps
3. After each set, estimate your RIR
4. **Stop** when your RIR reaches the cutoff
5. Log the number of sets completed

### TM Adjustment

| Condition | TM Change | Default |
|-----------|-----------|---------|
| Sets completed < lower threshold | Decrease | −5% |
| Sets completed ≥ lower AND ≤ upper threshold | No change | 0% |
| Sets completed > upper threshold | Increase | +2% |

**Default set threshold range**: 4–6 (lower = 4, upper = 6)
- Complete 3 or fewer sets → TM decreases by 5%
- Complete 4, 5, or 6 sets → TM unchanged
- Complete 7 or more sets → TM increases by 2%

### RIR Cutoff Table

The RIR cutoff varies by intensity. Higher RIR cutoffs at lower intensities (to limit fatigue from high-rep sets):

| %TM | RIR Cutoff |
|-----|-----------|
| 50–57.5% | 5 |
| 60–67.5% | 4 |
| 70–77.5% | 3 |
| 80–87.5% | 2 |
| 90–92.5% | 1 |
| 95–100% | 0 |

All lifts use the same default cutoffs. Customize per-exercise if needed.

### Rep Targets (Normal Sets)

All lifts share the same default rep targets:

| %TM | Reps |
|-----|------|
| 50–57.5% | 8 |
| 60–62.5% | 7 |
| 65–67.5% | 6 |
| 70–72.5% | 5 |
| 75–77.5% | 4 |
| 80–82.5% | 3 |
| 85–87.5% | 2 |
| 90–100% | 1 |

## Customization

### Set Thresholds (Per Exercise)
If you have better/worse strength endurance for certain lifts:
- OHP (recovers fast): lower = 6, upper = 8
- Deadlift (very fatiguing): lower = 3, upper = 4

### TM Adjustment Percentages (Per Exercise)
- Advanced lifters: reduce increase to +1% (slower, steadier progression)
- Novice lifters returning from layoff: increase to +3–4% temporarily
- Decrease percentage must be entered as a negative number

### RIR Cutoffs (Per Exercise)
- If a lift responds well to near-failure training: decrease cutoffs
- If you respond poorly to close-to-failure training: increase cutoffs (especially at higher %TM)

### Rep Targets (Per Exercise)
- Good strength endurance for a lift: increase rep targets
- Poor strength endurance for a lift: decrease rep targets
- Default rep targets are intentionally low to allow more high-quality sets

## Set Cap

If TMs are conservative and sets feel very easy, don't exceed ~12 sets. If things are still easy after set 6, consider shortening rest intervals instead of doing unlimited sets.

## Effort Requirement

The program only works if you genuinely push to reach and exceed the set targets. Don't treat the threshold as a prescription — it's a landmark. If you can do more sets below the RIR cutoff, do them. The TM will only progress if you sometimes exceed the upper threshold.

## Example Workout

Exercise: Squat, Week 1
- Intensity: 70% TM → Working weight calculated via formula
- Prescribed reps: 5 per set
- RIR cutoff: 3

You do sets of 5:
- Set 1: 5 reps, ~6 RIR → continue
- Set 2: 5 reps, ~5 RIR → continue
- Set 3: 5 reps, ~4 RIR → continue
- Set 4: 5 reps, ~3 RIR → hit cutoff, stop

Log 4 sets. That's within the 4–6 range → TM unchanged.

If you'd gotten to set 7 before hitting 3 RIR → TM increases by 2%.
If you hit 3 RIR on set 3 → only 3 sets, below threshold → TM decreases by 5%.
