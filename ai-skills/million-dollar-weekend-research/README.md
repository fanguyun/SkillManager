# million-dollar-weekend-research

以真实用户证据验证项目与商业机会的跨平台 Skill，覆盖调研、访谈、外联、预约/预售和决策。

## 目录

```text
million-dollar-weekend-research/
├── README.md
├── SKILL.md
├── agents/
│   └── openai.yaml
└── references/
    └── research-tables.md
```

## 用途

- 评估创业点子、新产品、服务或内部项目机会
- 设计用户访谈、验证外联、预约和预售实验
- 用结构化证据表形成 Go、调整或停止决策

## 安装

把该目录链接到你的 skill 目录，例如：

```bash
ln -s /path/to/million-dollar-weekend-research ~/.agents/skills/million-dollar-weekend-research
```
